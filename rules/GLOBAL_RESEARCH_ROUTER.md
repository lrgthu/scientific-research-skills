## Default Scientific Research Operating Protocol (Global Pinned Suite)

Whenever **any** conversation, `/plan`, `/boost`, `/goal`, `/teamwork` session, subagent (`invoke_subagent`), `run_workflow` pipeline, or `swarm` worker engages in **scientific or academic research**—across **all workspaces and scratch sessions**, without waiting for the user to explicitly name a skill—you **MUST** activate the **`scientific-research-skills`** suite by default:

| Research Lifecycle Stage & Trigger Signals | Mandatory Default Skill(s) to Read (`SKILL.md`) | Core Default Tooling & Non-Negotiable Output Contract |
| :--- | :--- | :--- |
| **1. Ideation, Novelty Check, Literature Survey, Baseline Selection, Citation Stance, & `.bib` Hygiene**<br>*(new research topic, hypothesis feasibility, prior-art check, related work, baseline hunting, retraction/stance audit, bibliography curation)* | `scholarly-graph-audit` + `literature-evidence-workflow`<br>*(Plugin: `research-literature`)* | Map seed lineages (`scholarly_graph.py lineage` + `render_citation_map.py`), audit citing stance & retractions (`citation-audit` / `tex-context`), unpack arXiv `.tar.gz` LaTeX (`unpack_paper_corpus.py` + `compile_evidence_matrix.py`), and verify every `.bib` key (`bib-verify`). ### Multi-Stage & Multi-Agent Research Rules

1. **Seamless Cross-Stage Chaining**: In end-to-end research sessions (e.g., *"survey X → implement & run experiment → plot & write up"*), transition automatically across Stages `1 → 2 → 3`, loading each stage's `SKILL.md` before executing that stage.
2. **Mandatory Subagent, Workflow, & Swarm Propagation**: Child agents (`research`, `self`, `run_workflow` nodes, `swarm` workers) start with fresh context and do not inherit files you already read. Whenever delegating any research subtask, explicitly instruct the child agent in its `Prompt`/`brief` to read the corresponding `SKILL.md` first.
3. **Clean Non-Research Exemption**: Everyday non-research tasks (homelab ops/DNS/monitoring changes, routine admin scripts, casual Q&A, email/calendar management, non-scientific app UI) remain **exempt** so daily operations stay zero-overhead.
