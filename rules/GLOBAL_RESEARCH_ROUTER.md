## Default Scientific Research Operating Protocol (Global Pinned Suite)

Whenever **any** conversation, `/plan`, `/boost`, `/grill-me`, `/goal`, `/teamwork` session, subagent (`invoke_subagent`), `run_workflow` pipeline, or `swarm` worker engages in **scientific or academic research**—across **all workspaces and scratch sessions**, without waiting for the user to name a skill—activate the **`scientific-research-skills`** 4-stage suite by default:

| Lifecycle Stage & Trigger Signals | Mandatory Default Skill(s) (`SKILL.md`) | Core Tooling & Output Contract |
| :--- | :--- | :--- |
| **0. Problem Selection, New Ideas, Hypotheses & Pre-Mortem**<br>*(brainstorming ideas, picking problems, critiquing raw ideas, fast kill-test design)* | `scientific-ideation` *(+ `scholarly-graph-audit` scoop check)*<br>*(Plugin: `scientific-ideation`)* | Ground in live scholarly friction (ban armchair `A+B` mashups), state Hamming Attack Vector + `cABT`, pit $\ge 2$ Platt hypotheses ($H_1$ vs. $H_2/H_0$), specify exact operator + iso-compute baseline + $\le 4\text{h}$ Crucial Experiment kill rule + Alon Cloud Pivot (`lint_research_ideas.py`). |
| **1. Literature Survey, Lineage, Stance/Retractions & `.bib`**<br>*(prior-art check, seed lineage, related work, comparison matrices, bibliography audit)* | `scholarly-graph-audit` + `literature-evidence-workflow`<br>*(Plugin: `research-literature`)* | Map seed lineages (`scholarly_graph.py lineage` + `render_citation_map.py`), audit citing stance & retractions (`citation-audit` / `tex-context`), unpack arXiv `.tar.gz` LaTeX (`unpack_paper_corpus.py` + `compile_evidence_matrix.py`), and verify every `.bib` key (`bib-verify`). |
| **2. Experiment Design, Data Pipelines, Simulation & Research Code**<br>*(scaffolding repos, implementing crucial/full experiments, MPS/MLX/CUDA scripts, tests, profiling)* | `scientific-computing`<br>*(Plugin: `scientific-computing`)* | Enforce read-only `data/raw/`, Tidy Data, `src/` library vs. `scripts/` drivers, `NaN`-safe `ValueError` bounds (`if not lo <= x <= hi:`), isolated `default_rng(seed)`, semantic filenames + `*_provenance.json` sidecars, analytical/invariant `pytest` oracles, and `audit_scientific_python.py`. |
| **3. Storyboarding, 2D Figures, Tables, Slides, Papers & Rebuttals**<br>*(plotting, tables, visual audits, drafting/revising manuscripts, proposals, talks, rebuttals)* | `scientific-writing` *(auto-co-loads `scientific-figures`)* / `scientific-figures`<br>*(Plugin: `scientific-writing`)* | Run the 5-Gate Assertion-Evidence Visual Audit first, enforce Anti-Patchwork Holistic Reconstruction (`OCAR` + `ABT` + `SCFL`), lock cross-artifact `Protocol P1/P2` numbers (`lint_manuscript_visuals.py`), format Booktabs tables & Okabe–Ito vector plots, and inspect rendered figures via `read_file`. |

### Multi-Stage & Multi-Agent Research Rules

1. **Seamless Cross-Stage Chaining (`0 → 1 → 2 → 3`)**: Transition automatically across Stages `0 → 1 → 2 → 3`, reading each stage's `SKILL.md` before executing that stage.
2. **Mandatory Subagent, Workflow, & Swarm Propagation**: Child agents (`research`, `self`, `run_workflow` nodes, `swarm` workers) start with fresh context; explicitly instruct every delegated research worker in its `Prompt`/`brief` to read the corresponding `SKILL.md` first.
3. **Standalone On-Demand LLM-Review Filter (`/llm-review-triage`)**: `llm-review-triage` is intentionally decoupled (`0` Always-On rules) and activated **only** when the user shares external AI/LLM-generated review comments or invokes `/llm-review-triage`.
4. **Clean Non-Research Exemption**: Everyday non-research tasks (homelab ops/DNS/monitoring changes, routine admin scripts, casual Q&A, email/calendar, non-scientific UI) remain **exempt**.
